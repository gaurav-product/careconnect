# CareConnect documentation

Start with the [case study](portfolio/portfolio-case-study.md). Everything else is the
working material behind it.

**One rule runs through all of it:** no fabricated evidence. Every source is graded A–D,
every unproven belief is labelled, and nothing claims traction that does not exist.
