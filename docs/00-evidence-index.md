# Evidence index

Every factual claim in these documents traces to a source in this list. Sources are
graded, because a government release and a home-care company's blog are not the same
kind of evidence and the difference matters when you are deciding what to build.

| Grade | Meaning |
| --- | --- |
| **A** | Government, multilateral or peer-reviewed. Treat as fact. |
| **B** | Commercial research house or established news outlet. Treat as fact with a margin. |
| **C** | Industry participant (a provider's own blog, a comparison site, a community post). Directionally useful, commercially motivated, never a statistic to quote. |
| **D** | Individual anecdote (complaint boards, forums). Evidence that a thing *happens*, never evidence of how often. |

## How claims are labelled in these documents

- **FACT** — supported by a grade A or B source, quoted with the figure and year.
- **OBSERVATION** — a pattern seen repeatedly across grade C/D sources; real, but not quantified.
- **HYPOTHESIS** — a testable belief the product is built on, with a named experiment.
- **ASSUMPTION** — something taken as true without evidence, listed so it can be attacked.

No user interviews were conducted for this project. Wherever a real product would have
primary research, this repository says **Not yet validated** instead of inventing a
number.
